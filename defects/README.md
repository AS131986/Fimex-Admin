## Формат

```markdown

- **Окружение:**
- **Браузер/платформа:**
- **Предусловия:**
- **Шаги воспроизведения:**
- **Ожидаемый результат:**
- **Фактический результат:**
- **Severity:**
- **Priority:**
- **Частота воспроизведения:**
- **Доказательства:**
- **Связанные Console/Network данные:**
- **Ссылка на требование:**
- **Статус подтверждения:**
```
