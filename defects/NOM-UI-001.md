# NOM-UI-001 — Текст подсказки в окне «Add model» ссылается на «category» вместо «model»

- **Страница:** Settings → Nomenclature → категория → «+ New Model»
- **Окружение:** стейдж `https://oman.itway.bz/`
- **Браузер/платформа:** Chrome (Claude in Chrome), роль супер админ
- **Предусловия:** открыт бренд с хотя бы одной категорией
- **Шаги воспроизведения:**
  1. Раскрыть любой бренд → любую категорию.
  2. Нажать «+ New Model».
  3. В открывшемся окне «Add model» прочитать текст под кнопкой «Save».
- **Ожидаемый результат:** текст подсказки должен ссылаться на текущую сущность — модель, например: «The "Data output" and "Product groups" tabs open after saving — they refer to the characteristics of an existing model.»
- **Фактический результат:** текст гласит «...they refer to the characteristics of an existing **category**» — слово «category» используется даже в контексте создания/редактирования модели. Похоже, текст захардкожен в общем компоненте формы (идентичен для окна «Add category», где он корректен) и не подставляет правильное название сущности для модели.
- **Severity:** Low (косметический текст, функциональность не нарушена).
- **Priority:** P3.
- **Частота воспроизведения:** воспроизведено 1 раз, стабильно по структуре компонента (ожидается 100%, т.к. текст статичный, не зависит от данных) — не переподтверждалось повторно в отдельном прогоне.
- **Доказательства:** скриншот сделан в ходе сессии тестирования 2026-11-14 (в истории диалога с QA Lead), не сохранён в `evidence/` — при необходимости переснять и приложить.
- **Связанные Console/Network данные:** нет (не проверялось для этого конкретного наблюдения).
- **Ссылка на требование:** явного BR в ТЗ по тексту этой подсказки нет — наблюдение зафиксировано из UI напрямую, без привязки к конкретному BR-NOM-*.
