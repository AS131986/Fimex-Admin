# Checklist — Номенклатура (этапы 1–2)

Покрывает: Этап 1 «Дерево и список», Этап 2 «Бренды, категории и модели — создание/редактирование/удаление». Скоуп и условия зафиксированы в `decisions.md` D-003. Содержимое вкладок «Главные»/«Вывод данных»/«Группы товаров» — отдельный чек-лист этапа 3. Товары — отдельный чек-лист этапа 4.

Тестовые сущности: `QA_TEST_Brand` → `QA_TEST_Category` → `QA_TEST_Model`.

## Дерево

- [ ] **NOM-F101 | P2** — Раскрытие свёрнутого уровня (▶) показывает дочерние элементы с отступом. [BR-NOM-001]
- [ ] **NOM-F102 | P2** — Сворачивание развёрнутого уровня (▼→▶) скрывает дочерние элементы. [BR-NOM-001]
- [ ] **NOM-F103 | P3** — Под уровнем без дочерних элементов показана только кнопка добавления, без признаков «пустого списка». [BR-NOM-002]
- [ ] **NOM-F104 | P2** — Кнопка «+ New Brand» видна на корневом уровне дерева. [BR-NOM-002]
- [ ] **NOM-F105 | P2** — Кнопка «+ New Category» видна под выбранным брендом. [BR-NOM-002]
- [ ] **NOM-F106 | P2** — Кнопка «+ New Model» видна под выбранной категорией. [BR-NOM-002]
- [ ] **NOM-F107 | P1** — Перетаскивание элемента внутри одного родителя меняет порядок и сохраняется после reload. [BR-NOM-003]

- [ ] **NOM-F201 | P1** — «+ New Brand» открывает окно «Добавить бренд» с полями: название, логотип light, логотип dark. [BR-NOM-019]
- [ ] **NOM-F202 | P1** — Создание `QA_TEST_Brand` с заполненным названием → бренд появляется в дереве. [BR-NOM-019]
- [ ] **NOM-F203 | P2** — Логотипы light/dark необязательны — бренд создаётся без них. [BR-NOM-007]
- [ ] **NOM-F204 | P1** — Правый клик по бренду открывает контекстное меню: Rename, Edit, Delete (без Duplicate). [BR-NOM-008, BR-NOM-020]
- [ ] **NOM-F205 | P1** — Rename бренда инлайн в дереве, сохранение по Enter. [BR-NOM-009]
- [ ] **NOM-F206 | P2** — Rename бренда инлайн, сохранение кликом вне поля. [BR-NOM-009]
- [ ] **NOM-F207 | P1** — Edit бренда открывает окно с предзаполненными текущими данными. [BR-NOM-010]
- [ ] **NOM-F208 | P1** — Delete бренда → подтверждение «Удалить бренд «Название»?» с кнопками «Отмена»/«Удалить». [BR-NOM-011]
- [ ] **NOM-F209 | P1** — Подтверждение удаления → бренд пропадает из дерева Номенклатуры и появляется в Архиве. [BR-NOM-011, BR-NOM-012, BR-NOM-077]
- [ ] **NOM-F210 | P2** — Отмена в диалоге удаления → бренд остаётся без изменений. [BR-NOM-011]

- [ ] **NOM-N203 | P1** — Название, совпадающее с существующим брендом без учёта регистра → «Бренд с таким названием уже существует.» [BR-NOM-016]
- [ ] **NOM-N204 | P3** — Пробелы в начале/конце названия обрезаются автоматически при сохранении. [BR-NOM-005]
- [ ] **NOM-N205 | P2** — Загрузка не-SVG файла как логотип → «Недопустимый формат файла.» [BR-NOM-017]

- [ ] **NOM-F305 | P1** — Правый клик по категории/модели открывает контекстное меню: Rename, Edit, Duplicate, Delete. [BR-NOM-008, BR-NOM-035]

## Категория/модель — негативные/ошибки

- [ ] **NOM-N301 | P1** — Пустое название → «Заполните название категории/модели.» [BR-NOM-014]
- [ ] **NOM-N302 | P2** — Название >100 символов → «Максимальная длина — 100 символов.» [BR-NOM-015]
