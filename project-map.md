# Project Map — Fimex Admin

Карта страниц веб-админки и статус их изучения/тестирования. Разделы и страницы админки пока не определены — будут добавлены по мере изучения приложения. Этот документ не придумывает структуру заранее.

## Статусы

- **Не изучено** — страница не исследована.
- **Изучается** — проводится анализ требований и/или UI.
- **Spec готов** — `spec.md` создан и подтверждён.
- **Checklist готов** — `checklist.md` создан.
- **В тестировании** — выполняются проверки.
- **Протестировано** — пройден полный цикл (функциональность + UI/UX + техническая проверка).
- **Заблокировано** — работа приостановлена (указать причину в примечаниях).
