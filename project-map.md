# Project Map — Fimex Admin

Карта страниц веб-админки и статус их изучения/тестирования. Структура меню зафиксирована по фактическому осмотру левой навигации (роль: супер админ, `leo@itway.bz`, окружение `https://oman.itway.bz/`). Статусы обновляются по мере изучения и тестирования.

## Статусы

- **Не изучено** — страница не исследована.
- **Изучается** — проводится анализ требований и/или UI.
- **Spec готов** — `spec.md` создан и подтверждён.
- **Checklist готов** — `checklist.md` создан.
- **В тестировании** — выполняются проверки.
- **Протестировано** — пройден полный цикл (функциональность + UI/UX + техническая проверка).
- **Заблокировано** — работа приостановлена (указать причину в примечаниях).

## Роли и окружение

- **Окружение:** `https://oman.itway.bz/` (название окружения/статус prod/staging не подтверждён — требует уточнения у QA Lead, см. `open-questions.md`).
- **Роли в самой админке (сторона Fimex):** admin, менеджер, менеджер отдела продаж, менеджер выдачи, менеджер склада, менеджер сервиса, супер админ (больше прав).
- **Роли со стороны поставщика:** поставщик, менеджеры поставщика — отдельный вид интерфейса, ограниченный работой с товарами. Не изучался в этой сессии.
- **Текущая изучаемая роль:** супер админ (`leo@itway.bz`, отображается в интерфейсе как «Александр»).
